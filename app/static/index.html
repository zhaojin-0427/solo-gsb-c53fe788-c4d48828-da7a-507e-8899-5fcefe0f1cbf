离线验证说明

凭证信封（credential envelope）是自包含的：包含签名头部、字段承诺明文与盐、模板版本定义，可导出离线保存。

  1. 在「② 签发端」签发后复制 credential JSON，保存为 credential.json。
  2. 用管理员接口 GET /api/keys/{kid} 取签发公钥，保存为 key.pem（密钥轮换后历史公钥仍可获取）。
  3. 生成只含指定字段的 presentation： 
    python offline_verify.py disclose credential.json --fields full_name,age -o presentation.json
  4. 离线验证（无需服务端；跳过在线撤销检查）： 
    python offline_verify.py verify presentation.json --public-key key.pem
